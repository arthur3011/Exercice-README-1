# Lecture d'un nombre avec Java Script

## Description
Ce projet est un exercice permet de demander à un utilisateur de saisir un nombre
dans le terminal, puis d'afficher le nombre saisi.

## Technologies utilisées
- JavaScript
- Node.js
- Visual Studio Code
- Git
- GitHub

## Prérequis
Node.js doit être installé sur l'ordinateur.

## Exécution du programme
Dans le terminal, exécuter la commande :
node index.js


## Fonctionnement
1. Le programme demande à l'utilisateur de saisir un nombre.
2. La saisie est convertie en nombre avec `Number()`.
3. Le résultat est affiché dans le terminal.
